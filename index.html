📐 Формула объективной сложности SDP v2.0 (SwipEdit's Difficulty Points)
В отличие от ручного поля difficulty в meta.json (которое в игре ограничено 10.0★ и выставляется автором вручную), оценка SDP и Честные звёзды (Auto ★) вычисляются напрямую из физики чарта: интервалов между нотами, скорости и дёрганий скролла, геометрии паттернов и тяжести визуальных эффектов — без потолка и без привязки к конкретным картам. Это позволяет объективнее оценивать сложность у множества различных карт.
1. Временное расстояние между нотами (Δt_mean, Δt_p25) и плотность:
T_span = max(1.0, t_last − t_first)  |  NPS_avg = N_notes / T_span
R_spacing = 0.55 · (1 / max(0.075, Δt_mean)) + 0.45 · (1 / max(0.065, Δt_p25))
Учитывается не только средний NPS по карте, но и реальная дистанция Δt_mean между соседними нотами и плотность быстрых сплитов/стримов (25-й перцентиль Δt_p25).
2. Паттерны, углы, джеки, стаки, реверсы и наслоение (w_i):
w_i = 1.0 + 0.60·(k_i − 1) + 0.16·D_i + 0.72·R_i + P_jack + P_turn + P_zigzag + P_overlap
• k_i — вертикальный стак (≤ 5 мс); D_i — диагональ; R_i — REVERSE / REVERSE_BACK;
• P_jack — быстрый повтор одного направления подряд (Δθ = 0° при Δt < 0.32 с);
• P_turn и P_zigzag — резкие смены угла ≥ 90° и серии зигзагов из 3+ нот;
• P_overlap — визуальное сближение соседних нот на дорожке (Δt · 1000 < 0.20 · T_eff).
3. Скорость скролла, турбулентность скорости и мгновенный стрейн (M_scroll, strain_i):
T_eff(i) = noteTravelTime / NOTE_SPEED(i)
M_scroll(i) = (1000 / clamp(T_eff, 160, 1000))^0.58 · (1 + 0.30·max(0, (T_eff − 1350)/1000)^0.70) · S_shock
strain_i = (w_i · M_scroll(i)) / (max(0.055, Δt_i))^0.78
Высокая скорость пролёта (2x–5x, когда на чтение ноты остаётся 200–500 мс) и частые рывки NOTE_SPEED (S_shock) кратно повышают нагрузку на реакцию.
4. Нагруженность по эффектам (FX_load) по тяжести для восприятия:
FX_load = ∑ (W_fx(type) · dur^0.35 · decay) + 0.95·N_spd_switches + 0.45·∑|Δspeed|
M_fx = 1 + min(0.32, 0.018 · FX_load^0.72)  |  FX_pts = 4.2 · FX_load^0.70 · clamp(0.5 + 0.5·(NPS_avg / 2.8), 0.5, 1.6)
• Тяжёлые (вес 2.1–4.5): BLACKOUT, FX_DREAD, FX_GLITCH, NOTES_SPIN_ON, NOTE_PUSH_ON, FX_OLD_TV, FX_ZOOM_BLUR, FX_INVERT, DISCO, FX_PIXELATE;
• Средние (вес 1.0–1.9): NOTES_WAVE_ON, FX_WAVE, FX_RGB_SPLIT, NOTES_BOUNCE_ON, FX_HALFTONE, FX_ASH_WIND, FX_AQUA, HUD_HIDE;
• Лёгкие (вес 0.10–0.65): FX_DUOTONE, FX_BW, CAMERA_BOB_ON, SHAKE, FLASH, BG_COLOR, TEXT.
5. Зависимость множителя длины от среднего NPS (L_mod) и расчёт Честных звёзд (Auto ★):
T_ref = clamp(92 / (1 + 0.34·max(0, NPS_avg − 2.0) + 0.22·max(0, M_scroll_avg − 1.15)), 32, 92)
L_mod = clamp(T_span / T_ref, 0.22, 1.55)^0.42 · (1 + 0.22·max(0, (N_eff − 220)/170))
SDP = (16.0·NPS_avg·M_scroll^0.55 + 9.5·R_spacing·M_scroll^0.45 + 7.2·NPS_peak3s + 4.8·mean(strain) + 3.1·P90(strain)) · L_mod · M_fx + E_pts + FX_pts
Auto ★ = round_0.5((SDP / 53.0)^0.82)
Чем выше средний NPS и скорость скролла, тем быстрее карта выходит на полный множитель длины L_mod ≥ 1.0 (интенсивный 50-секундный уровень не занижается из-за хронометража).
